GST Filing & E-Invoice, Step by Step

How GSTR-1, GSTR-3B, GSTR-2B reconciliation and E-Invoice/IRN actually work inside Accelent 2.3.1 — and exactly where Accelent's job ends and the government portal's job begins.

Covers: GST Returns panel · E-Invoice panel
Country profile: India

✅ What Accelent actually does

Builds portal-ready GSTR-1/GSTR-3B JSON and Excel working papers from your real sales & purchase data, auto-tracks your GST ledger and ITC, and matches a downloaded GSTR-2B file against your books line by line.

🖐 What you still do on the portal

Upload the generated JSON at gst.gov.in, actually file the return, get the ARN back, and — for e-Invoice — generate the real IRN at einvoice1.gst.gov.in. Accelent never submits anything on your behalf.

01

Prerequisite — HSN code & GST rate on every item

Everything downstream (GSTR-1's HSN summary, the e-Invoice JSON) is pulled from these two fields, so this has to be right before you file anything.

1

Open Inventory → Add/Edit Item ui/inventory/inventory_panel.py

Fill in HSN Code (alphanumeric, validated) and GST Rate (%) for every item you sell. These save to the inventory table as hsn_code and gst_rate.

2

Optional: export a GST/HSN-wise stock summary

Inventory panel has an export button tooltipped "Export a GST / HSN-wise stock summary for return filing" — a quick sanity check before your first filing.

02

One-time setup — GST Returns → Configuration

Do this once. Sidebar → GST Returns, opens 11 tabs; start on the first.

1

⚙️ Configuration tab

Enter your Company GSTIN, Company Name, Registration State, and Filing Frequency (Monthly or Quarterly). Click Save. This GSTIN is what every later export and the e-Invoice JSON pulls from — get it right the first time.

03

What happens automatically, all period long

Nothing to click here — this runs in the background as you use the app normally.

—

📒 GST Ledger fills itself Automatic

Every sale, purchase, and credit/debit note posts a row to the GST Ledger tab as it happens. You can filter and review it any time, or hit 📄 Export Ledger for a CSV/Excel copy for your own records — this is not a portal upload file, just your working record.

04

Filing GSTR-1 (outward supplies)

GST Returns → 📈 Reports tab.

1

(Optional) 📈 Generate GSTR Summary

An on-screen breakdown before you commit to anything — B2B, B2C-Large, B2C-Small and HSN summary, pulled straight from sales_invoices/sales_items.

2

📊 Export GSTR-1 Excel — review first Real export

A working-paper .xlsx with separate sheets: Summary, B2B (Table 4), B2C-Large (Table 5), B2C-Small (Table 7), HSN Summary (Table 12). Open it, check the numbers look right — this is your last chance before the portal-facing file.

3

📥 Export GSTR-1 JSON — the file you actually upload Real export

Builds a real GSTR-1-shaped JSON (b2b / b2cs / b2cl / hsn / cdnr / exp / nil sections) matching the GST portal's own offline-tool schema, and saves it via a file dialog.

📄 GSTR1_<period>_<date>.json
4

Upload & file on the GST portal You do this

Go to gst.gov.in → Returns → the Returns Offline Tool → upload that JSON → review → file. Accelent stops at handing you the file.

05

Filing GSTR-3B (summary return & payment)

Same Reports tab, same rhythm.

1

📑 Calculate GSTR-3B

Computes outward liability, ITC available, and net payable. If the period is overdue, it automatically adds 18% p.a. interest and the applicable late fee — worth checking before you assume the number shown is what you'd pay on time.

2

Save → exports GSTR-3B JSON Real export

Same offline-tool-style JSON pattern as GSTR-1 — hand this to the portal's GSTR-3B utility.

3

File & pay on the portal You do this

Upload, verify the auto-populated figures against your own, pay, and file.

Also available 📅 Annual GSTR-9 works the same way — an annual summary you export at year-end, filed the same manual way.
06

Closing the loop — log the filing back into Accelent

Accelent has no way to know a return was filed unless you tell it.

1

📊 Returns tab → ➕ Add Return Record

Type in the Period, Type (GSTR-1/3B/9), Due Date, Filed Date, Liability, and Status, plus the ARN the portal gave you after filing. This is bookkeeping only — nothing here talks to the portal.

2

💰 ITC Register → Claim ITC for Current Period

Marks the period's input tax credit as claimed in your own records once you've actually claimed it in the return.

3

🔄 Reconciliation tab

A sanity check — compares your books' total period liability against the liability you actually filed, so a mismatch is caught before it compounds next period.

07

GSTR-2B Reconciliation (the one real portal-file import)

The only place Accelent reads a government file back in, rather than only producing one.

1

Download your GSTR-2B from the portal

gst.gov.in → Returns Dashboard → GSTR-2B, download the .xlsx for the period.

2

🧾 GSTR-2B Reconciliation tab → 📥 Import GSTR-2B (.xlsx) Real matching

Matches its B2B invoices line-by-line against your own purchases table — flags matched, fuzzy-matched, amount mismatches, invoices missing from your books, duplicates, and entries in your books that never showed up in 2B. This is exactly what catches ITC you're entitled to but haven't recorded.

3

📄 Export CSV

Hand the flagged report to your accountant, or work through it yourself before the ITC claim deadline for the period.

08

E-Invoice & IRN

Sidebar → E-Invoice. Read this section fully before you rely on it — the IRN part is not automated.

Be clear on this before you start Accelent builds a real, portal-compatible e-Invoice JSON. It does not call the government's IRP API to fetch a real IRN — there's an "IRP Credentials" tab where you can save API credentials, but nothing in the app currently makes a live connection with them. Getting the actual IRN still happens on the government side, outside Accelent.
1

📄 Generate JSON tab

Search and pick the sales invoice you need an IRN for, then ▶ Preview JSON. Builds the real NIC e-Invoice schema v1.1 payload (SellerDtls / BuyerDtls / ItemList / ValDtls, with proper state-code lookups).

2

📥 Download JSON Real export

Saves the payload to disk. Accelent shows you exactly where it goes next: einvoice1.gst.gov.in → Others → Bulk Generate IRN.

3

Generate the IRN on the portal (or via a GSP) You do this

Upload the JSON at the e-Invoice portal, or hand it to your GST Suvidha Provider if you use one. You get back a real IRN, an acknowledgement number/date, and a signed QR code — none of which Accelent generates itself.

Known gap — there's currently no field to bring the IRN back in Accelent has the data model ready for this (an IRN Log tab, and irn/ack_no/ack_date columns on the invoice), but nothing in the current build actually writes to them — so once you have the real IRN from the portal, there's no working "paste it back in" step yet. Until that's built, keep the IRN/QR code with your filing records outside Accelent (or in the invoice's own Notes field as a practical workaround), not inside the IRN Log tab.
