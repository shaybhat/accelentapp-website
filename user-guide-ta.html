அத்தியாயம் 1 — அறிமுகம்

1. Accelent என்றால் என்ன?

💡 Accelent இன் கீழே உள்ள 📖 User Guide பொத்தான் மூலம் எப்போது வேண்டுமானாலும் இந்த வழிகாட்டியைத் திறக்கலாம், அல்லது F1 அழுத்துங்கள்.

Accelent என்பது சிறு மற்றும் நடுத்தர வணிகங்களுக்காக — கடைகள், விநியோகஸ்தர்கள், மொத்த வியாபாரிகள் மற்றும் சேவை வழங்குநர்களுக்காக — உருவாக்கப்பட்ட முழுமையான கணக்கியல் மற்றும் சரக்கு மேலாண்மை அமைப்பு. இது Windows PC இல் இயங்குகிறது, ஒரு Android மொபைல் செயலியுடன் இணைகிறது, எனவே உங்கள் வணிகத்தை எங்கிருந்தும் பார்க்கலாம்.

🖥️ டெஸ்க்டாப் செயலி

முழு அம்சங்களுடன் கணக்கியல், பில்லிங், சரக்கு, GST ரிட்டர்ன், சம்பளம் மற்றும் அறிக்கைகள். அனைத்தும் உங்கள் Windows PC இல் இயங்கும். தினசரி பயன்பாட்டிற்கு இணையம் தேவையில்லை.

📱 மொபைல் செயலி

நேரடி விற்பனை, சரக்கு மற்றும் நிலுவைகளை உங்கள் போனிலிருந்து பாருங்கள். தொலைவிலிருந்தே இன்வாய்ஸ்களும் கொள்முதல்களும் உருவாக்குங்கள். உங்கள் உள்ளூர் WiFi மூலமாகவோ, Tailscale வழியாக எங்கிருந்தும் டெஸ்க்டாப்புடன் இணைகிறது.

📊 இது என்னவற்றை நிர்வகிக்கிறது

விற்பனை இன்வாய்ஸ்கள் · கொள்முதல் பில்கள் · சரக்கு மற்றும் இருப்பு · தரப்பினர் (வாடிக்கையாளர்கள் மற்றும் சப்ளையர்கள்) · வங்கி மற்றும் ரொக்கக் கணக்குகள் · ஊழியர்கள் மற்றும் சம்பளம் · GST மற்றும் இ-இன்வாய்சிங் (இந்தியா), மேலும் பாகிஸ்தான், இலங்கை மற்றும் Simple VAT நாடுகளுக்கான வரி

🔒 உங்கள் தரவு உங்களுடையதே

எல்லாத் தரவும் உங்கள் PC யில் ஒரே தரவுத்தளக் கோப்பில் சேமிக்கப்படுகிறது. எந்த கிளவுட் சர்வருக்கும் எதுவும் அனுப்பப்படுவதில்லை. அது முழுமையாக உங்களுக்குச் சொந்தம்.

அத்தியாயம் 2 — கணக்கியல் அடிப்படைகள்

2. புதியவர்களுக்கான கணக்கியல் அடிப்படைகள்

கணக்கியல் மென்பொருளுக்கு நீங்கள் புதியவர் என்றால், முதலில் இந்தப் பகுதியைப் படியுங்கள். கணக்கியலில் பட்டம் தேவையில்லை — சில முக்கியக் கருத்துகளைப் புரிந்துகொண்டால் போதும்.

💰 ரொக்கம் vs வங்கி

உங்கள் வணிகத்தின் பணம் இரண்டு இடங்களில் உள்ளது: கையில் உள்ள ரொக்கம் (உங்கள் டிராயரில் உள்ள நோட்டுகள்) மற்றும் வங்கிக் கணக்குகள் (வங்கியில் உள்ள பணம்). Accelent இரண்டையும் தனித்தனியாகக் கணக்கிடுகிறது. ரொக்கம் பெறும்போது ரொக்க நிலுவை உயரும். வங்கியில் டெபாசிட் செய்யும்போது ரொக்கம் குறையும், வங்கி உயரும்.

🧾 இன்வாய்ஸ் (விற்பனை பில்)

வாடிக்கையாளர் உங்களிடம் வாங்கும்போது அவருக்குக் கொடுக்கும் பில்தான் இன்வாய்ஸ். அதில் பொருட்கள், அளவுகள், விலைகள் மற்றும் மொத்தத் தொகை இருக்கும். Accelent இல் ஒவ்வொரு இன்வாய்ஸும் பதிவு செய்யப்பட்டு, வாடிக்கையாளரின் கணக்குடன் தானாக இணைக்கப்படுகிறது.

🛒 கொள்முதல் பில்

பொருட்கள் வாங்கும்போது சப்ளையரிடமிருந்து பெறும் பில்தான் கொள்முதல் பில். அதை Accelent இல் பதிவு செய்தால் உங்கள் சரக்கு இருப்பு தானாக உயரும், அந்த சப்ளையருக்குக் கொடுக்க வேண்டிய தொகையும் பதிவாகும்.

👥 தரப்பினர் (வாடிக்கையாளர்கள் மற்றும் சப்ளையர்கள்)

தரப்பினர் (Party) என்பது நீங்கள் வழக்கமாக வணிகம் செய்யும் எவரும். வாடிக்கையாளர்கள் உங்களுக்குப் பணம் தர வேண்டியவர்கள் (வரவு — பச்சையில் காட்டப்படும்). சப்ளையர்கள் நீங்கள் பணம் தர வேண்டியவர்கள் (செலுத்த வேண்டியது — சிவப்பில் காட்டப்படும்). எல்லாப் பரிவர்த்தனைகளிலிருந்தும் ஒவ்வொரு தரப்பினரின் நிலுவையையும் Accelent தானாகக் கணக்கிடுகிறது.

📦 சரக்கு / இருப்பு

சரக்கு என்பது நீங்கள் விற்கும் பொருட்களின் பட்டியல். ஒவ்வொரு பொருளுக்கும் Accelent இருப்பில் உள்ள அளவு, விற்பனை விலை, கொள்முதல் விலை மற்றும் குறைந்தபட்ச இருப்பு அளவு (மீண்டும் ஆர்டர் செய்ய எப்போது எச்சரிக்க வேண்டும்) ஆகியவற்றைக் கண்காணிக்கிறது.

⚖️ தொடக்க நிலுவை

Accelent ஐ முதல் முறையாகப் பயன்படுத்தத் தொடங்கும்போது, ஏற்கனவே உங்களிடம் உள்ளதை மென்பொருளுக்குச் சொல்ல வேண்டும் — எவ்வளவு ரொக்கம், ஒவ்வொரு வங்கிக் கணக்கிலும் எவ்வளவு, ஒவ்வொரு வாடிக்கையாளரும் உங்களுக்கு எவ்வளவு தர வேண்டும், நீங்கள் ஒவ்வொரு சப்ளையருக்கும் எவ்வளவு தர வேண்டும். இவை தொடக்க நிலுவைகள் (Opening Balances) எனப்படும், ஆரம்ப அமைப்பின்போது ஒரு முறை மட்டும் உள்ளிடப்படும்.

🧮 டெபிட் / கிரெடிட் (எளிமையாக)

Accelent இல் டெபிட்/கிரெடிட் பதிவுகளைப் பற்றி நீங்கள் கவலைப்பட வேண்டியதில்லை — மென்பொருளே அதைத் தானாகக் கையாள்கிறது. விற்பனையைப் பதிவு செய்தால் அது உங்கள் வருமானத்திலும் வாடிக்கையாளரின் நிலுவையிலும் சேரும். கொள்முதலைப் பதிவு செய்தால் அது உங்கள் இருப்பிலும் சப்ளையர் நிலுவையிலும் சேரும். நடந்ததைப் பதிவு செய்தால் போதும் — கணக்கியலை Accelent பார்த்துக்கொள்ளும்.

தொடங்கும் முன் — உங்கள் நாட்டைத் தேர்ந்தெடுங்கள்

Accelent முதல் முறை தொடங்கும்போது (நீங்கள் சொந்தக் கடவுச்சொல் அமைத்த உடனே), உங்கள் நாட்டைக் கேட்கும். நாடு உங்கள் வரி விதிகளையும் நாணயத்தையும் தீர்மானிக்கிறது — இந்தியாவுக்கு GST, மற்ற நாடுகளுக்கு VAT — எனவே ஒவ்வொரு இன்வாய்ஸும் அறிக்கையும் வரி ரிட்டர்னும் முதல் நாளிலிருந்தே சரியான விகிதங்களைப் பயன்படுத்தும்.

1

3
Language ஐச் சரிபாருங்கள். அதில் உங்கள் நாட்டின் முதன்மை மொழி முன்கூட்டியே நிரப்பப்பட்டிருக்கும் (உதாரணமாக இந்தியாவுக்கு Hindi) — அதை English அல்லது நீங்கள் விரும்பும் வேறு மொழிக்கு மாற்றுங்கள்.
4
உங்கள் Business ஐத் தேர்ந்தெடுங்கள்: Shop, trading, services or manufacturing, Restaurant, café or dhaba (அத்தியாயம் 9b பார்க்கவும்) அல்லது Hotel, lodge or guest house (அத்தியாயம் 9c பார்க்கவும்). மெனு எந்தத் திரைகளைக் காட்டும் என்பதை இது தீர்மானிக்கிறது, பின்னர் Settings → 🏢 Company இல் மாற்றலாம்.

Confirm and Continue கிளிக் செய்யுங்கள்.

அளவுகள் அல்லது விலைகள் 0 ஆக வந்தனஅளவு நெடுவரிசை Stock க்கும் விலை நெடுவரிசை Purchase Rate க்கும் அமைக்கப்பட்டுள்ளதா என்று பார்த்து, மீண்டும் இறக்குமதி செய்யுங்கள் — ஏற்கனவே உள்ள பொருட்கள் புதுப்பிக்கப்படும்.

அத்தியாயம் 8 — சரக்கு

8. சரக்கு பேனல்

நீங்கள் விற்கும் ஒவ்வொரு பொருளையும் Inventory கண்காணிக்கிறது — இருப்பு அளவுகள், விலைகள், வகைகள் மற்றும் காலாவதி தேதிகள்.

புதிய பொருளைச் சேர்த்தல்

1
பொருள் பட்டியலுக்கு மேலே ➕ Add New Item என்பதைக் கிளிக் செய்து, இடப்புறம் உள்ள Add / Edit Item படிவத்தை நிரப்புங்கள்.
2
நிரப்புங்கள்: Item Name, Category, Vendor, Buy Rate (நீங்கள் கொடுத்த விலை), Sell Price (நீங்கள் வாங்கும் விலை — அதன் கீழே Margin காட்டப்படும்), GST %, Unit (pcs, kg, litre, metre… — kg, litre மற்றும் பிற அளவீட்டு அலகுகளில் 0.25 போன்ற பகுதி அளவுகள் செல்லும்), Stock (இப்போது உங்களிடம் எத்தனை உள்ளன) மற்றும் குறைந்தபட்ச இருப்பு அளவு (எச்சரிக்கை எல்லை). பொருள் குறியீட்டுக்கு 🔍 Generate Smart Code கிளிக் செய்யுங்கள்.
3
விரும்பினால் சேருங்கள்: Sub Category, Barcode, MRP (விலையைக் கணக்கிட Calculate from MRP + Discount % பயன்படுத்துங்கள்), HSN Code (GST க்கு), Expiry Date (கெட்டுப்போகும் பொருட்களுக்கு). இந்தியாவில், 4 அல்லது அதற்கு மேற்பட்ட இலக்க HSN குறியீட்டை உள்ளிட்டால் அந்தக் குறியீட்டுக்கான GST % தானாக அமையும்.
4
Save என்பதைக் கிளிக் செய்யுங்கள்.
💡 மார்ஜினை விரைவாக மாற்றுதல்: Sell Price க்குக் கீழே உள்ள Margin: x% மீது மவுஸை வைத்து வீலைச் சுழற்றுங்கள் — ஒவ்வொரு படியும் மார்ஜினை 1% உயர்த்தும் அல்லது குறைக்கும் (0.1% க்கு Ctrl அழுத்திப் பிடியுங்கள்), Sell Price மீண்டும் Buy Rate இலிருந்து கணக்கிடப்படும். இறக்குமதி செய்த பொருட்கள் 20% இல் தொடங்குகின்றன, எனவே நீங்கள் விரும்பும் மார்ஜினை அமைக்க இதுவே வேகமான வழி.

பொருட்களை நீக்குதல்

ஒருபோதும் வாங்கப்படாத, விற்கப்படாத, திருப்பப்படாத அல்லது நகர்த்தப்படாத பொருளை மட்டுமே நீக்க முடியும். வரலாறு உள்ள பொருட்கள் Inventory இல் இருக்கும், அதனால் உங்கள் பில்கள், அறிக்கைகள் மற்றும் இருப்புப் பதிவுகள் முழுமையாக இருக்கும். நீக்கப்பட்ட ஒவ்வொரு பொருளும் Deletion Watcher இல் வைக்கப்படுகிறது, அங்கிருந்து அதன் இருப்புடன் மீட்டெடுக்கலாம்.

சரக்கு இறக்குமதி மூலம் வந்த பொருள் தவறாக இறக்குமதி செய்யப்பட்டிருந்தால், நிர்வாகி அதை நீக்கலாம் (தேர்ந்தெடுங்கள் → Delete Selected → நிர்வாகி கடவுச்சொல்). இது அதன் தொடக்க இருப்பையும் நீக்குகிறது; உறுதிப்படுத்தல் அளவையும் மதிப்பையும் காட்டும். அந்தப் பொருளுக்கு எதுவும் வாங்கப்படாமல், விற்கப்படாமல் அல்லது திருப்பப்படாமல், அதன் இருப்பு இறக்குமதி கொண்டுவந்த அளவாகவே இருந்து, இறக்குமதியின் நிதியாண்டு மூடப்படாத வரை மட்டுமே இது அனுமதிக்கப்படும்.

1
பயன்படுத்தப்படாத பல பொருட்களை ஒரே நேரத்தில் நீக்க, 🧹 Clean Up Unused Items கிளிக் செய்யுங்கள் (நிர்வாகிக்கு மட்டும் தெரியும்). ஒருபோதும் வாங்கப்படாத அல்லது விற்கப்படாத ஒவ்வொரு பொருளையும் இது பட்டியலிடும்.
2
நீக்க வேண்டிய பொருட்களைத் டிக் செய்து (தேடல் பெட்டி அல்லது Select All shown பயன்படுத்துங்கள்), 🗑️ Delete Selected Items கிளிக் செய்து நிர்வாகி கடவுச்சொல்லுடன் உறுதிப்படுத்துங்கள். முதலில் உங்கள் தரவின் பேக்கப் சேமிக்கப்படும்.

சரக்கு அறிக்கைகள்

Inventory Reports பேனல் (முதன்மை Inventory யிலிருந்து தனி) இருப்பு மதிப்பீட்டு அறிக்கைகள், நகர்வு வரலாறு மற்றும் வகைவாரிச் சுருக்கங்களைத் தருகிறது. மாதாந்திர இருப்புத் தணிக்கைக்கு இதைப் பயன்படுத்துங்கள்.

தணிக்கைத் தடம் (Audit Trail)

Audit Trail டேப் (Inventory Management க்குள்) ஒவ்வொரு இருப்பு மாற்றத்தையும் — விற்பனை, கொள்முதல், சரிசெய்தல், திருப்புதல் மற்றும் இறக்குமதி — ஒரு Value நெடுவரிசையுடனும், நீங்கள் வடிகட்டியவற்றுக்கான தொடர் Total value உடனும் பட்டியலிடுகிறது. ஒரு மொத்த இறக்குமதி வணிகத்திற்கு எவ்வளவு இருப்பு மதிப்பைக் கொண்டுவந்தது என்று பார்க்க Reason = "import" என்று வடிகட்டுங்கள். தற்போதைய வடிகட்டிய பட்டியலை அச்சிட 🖨️ Print Report பயன்படுத்துங்கள். இந்த டேப் படிக்க மட்டுமே — ஒரு பொருளின் இருப்பைத் திருத்த அல்லது நீக்க, Inventory Management டேபுக்குச் செல்லுங்கள்.

காலாவதி எச்சரிக்கைகள்

Expiry Alerts பேனல் காலாவதி தேதியை நெருங்கும் பொருட்களைப் பட்டியலிடுகிறது. பொருட்கள் ஆரஞ்சு (விரைவில் காலாவதி) அல்லது சிவப்பில் (காலாவதியானது) குறிக்கப்படும். Set Expiry அல்லது Print Report க்கு எந்த வரிசையிலும் வலது-கிளிக் செய்யுங்கள். விற்கும் முன் காலாவதியான இருப்பை அகற்ற இதைப் பயன்படுத்துங்கள்.

⚠ விற்பனையைப் பதிவு செய்யும்போது (இருப்பு குறையும்) அல்லது கொள்முதலைப் பதிவு செய்யும்போது (இருப்பு உயரும்) இருப்பு அளவுகள் தானாக மாறும். உண்மையான இருப்புத் தணிக்கை தவிர, ஒருபோதும் இருப்பைக் கையால் கூட்டவோ கழிக்கவோ வேண்டாம்.
அத்தியாயம் 8b — குறைந்த இருப்பு கண்காணிப்பு

8b. குறைந்த இருப்பு கண்காணிப்பு

Low Stock Monitor தன் குறைந்தபட்ச இருப்பு அளவில் அல்லது அதற்குக் கீழே உள்ள ஒவ்வொரு பொருளையும் பட்டியலிட்டு, மீண்டும் ஆர்டர் செய்ய இரண்டு வழிகளைத் தருகிறது: புதிய பொருளையும் புதிய சப்ளையரையும் ஒன்றாகப் பதிவு செய்ய ஒரு விரைவு வழிகாட்டி, முறையான கொள்முதல் ஆர்டர் உருவாக்க முழுமையான "Order from Vendor" திரை. Purchase பேனலின் New Purchase போலல்லாமல், இங்கே உருவாக்கப்படும் ஆர்டர்கள் வரைவுகள் (drafts) — நீங்கள் அனுப்பி, பெற்ற பொருட்களைப் பதிவு செய்யும் வரை அவை இருப்பையோ சப்ளையர் நிலுவையையோ தொடுவதில்லை.

எவ்வளவு செலவாகிறது

ஒரு ஓட்டத்தின் செலவு = பயன்படுத்திய மூலப்பொருட்கள் (அவற்றின் சராசரி கொள்முதல் விலையில்) + கூலி மற்றும் பிற செலவுகள். தயாரான பொருளின் Buy Rate அதன் சராசரி உற்பத்திச் செலவாகிறது, எனவே உங்கள் இருப்பு மதிப்பும் ஒவ்வொரு விற்பனையின் லாபமும் அதைத் தயாரிக்க உண்மையில் ஆன செலவிலிருந்து கணக்கிடப்படுகின்றன. தயாரான பொருட்களை வழக்கம்போல் Sales இல் விற்பனை செய்யுங்கள்.

ஆர்டரின் பேரில் சமைக்கப்படும் உணவுகள் (உணவகங்கள்)

உணவக உணவு முன்கூட்டியே தயாரிக்கப்படுவதில்லை, ஆர்டர் வரும்போது சமைக்கப்படுகிறது. அதன் சமையல் குறிப்பில் Made to order டிக் செய்யுங்கள்: அப்போது உணவுக்குச் சொந்த இருப்பு இருக்காது, ஒவ்வொரு முறை விற்கும்போதும் அதன் பொருட்கள் இருப்பிலிருந்து எடுக்கப்படும் (பில் மாற்றப்பட்டால் அல்லது நீக்கப்பட்டால் அவை திரும்பும்). ஸ்டோரில் அதன் பொருட்கள் போதுமான அளவு இருந்தால் மட்டுமே உணவை விற்க முடியும். Made to order உணவுகள் Make டேபில் பட்டியலிடப்படுவதில்லை, குறைந்த இருப்புப் பட்டியல்களிலிருந்தும் விடப்படுகின்றன. அத்தியாயம் 9b — உணவகம் பார்க்கவும். Made to order உணவு ஒருபோதும் வாங்கப்படுவதில்லை: அதைக் கொண்ட கொள்முதல், கொள்முதல் ஆர்டர் அல்லது போன் கொள்முதல் மறுக்கப்படும், அதற்குப் பதிலாக அதன் பொருட்களை வாங்குமாறு செய்தி வரும்.

💡 கடன் விற்பனை: பணம் செலுத்தலில் "Credit" தேர்ந்தெடுத்தால், இன்வாய்ஸ் Unpaid எனக் குறிக்கப்பட்டு, தொகை வாடிக்கையாளரின் வரவு நிலுவையில் சேர்க்கப்படும். அவர் பின்னர் செலுத்தும்போது, Receipts பேனலில் ரசீதாகப் பதிவு செய்யுங்கள்.
அத்தியாயம் 9b — உணவகம் உணவகங்கள் மற்றும் ஹோட்டல்களுக்கு

9b. உணவகம் (மேசைகள், சமையலறைச் சீட்டுகள் மற்றும் பில்கள்)

உணவகம், கஃபே, தாபா அல்லது ஹோட்டல் சமையலறைக்கு Accelent இல் 🍽 Restaurant திரை உள்ளது: ஒரு மேசையைத் தட்டுங்கள், உணவுகளைத் தட்டுங்கள், சமையலறைக்கு ஒரு சமையலறைச் சீட்டு (KOT) அனுப்புங்கள், விருந்தினர் கிளம்பும்போது மேசைக்கு பில் போடுங்கள். ஒவ்வொரு பில்லும் சாதாரண விற்பனையாகச் சேமிக்கப்படுகிறது, எனவே Accounts, GST மற்றும் அறிக்கைகளில் அது சேர்கிறது, ஒவ்வொரு உணவும் பயன்படுத்தும் பொருட்கள் தானாக இருப்பிலிருந்து குறைகின்றன.

உங்கள் மெனுவை அமைத்தல்

💡 மாதிரி மெனுவுடன் தொடங்குங்கள்: மெனு காலியாக இருக்கும் வரை, Restaurant திரை 📋 Start with a sample menu வழங்குகிறது (⚙ Restaurant Settings இலும் உள்ளது). இது மெனுப் பிரிவுகளில் 53 பொதுவான உணவுகளையும் பானங்களையும் (ஸ்டார்டர்கள், மெயின் கோர்ஸ், சாதம், ரொட்டிகள், காலை உணவு, இனிப்புகள், சூடான மற்றும் குளிர் பானங்கள், ஜூஸ்கள், மாக்டெயில்கள்), அலகுகளுடன் சுமார் 100 பொருட்களையும், ஒவ்வொரு உணவுக்கும் ஒரு Made to order சமையல் குறிப்பையும் சேர்க்கிறது; இன்னும் அறைகள் இல்லாத ஹோட்டலுக்கு அறைகள் 101–104 மற்றும் 201–204 உம். உங்களிடம் ஏற்கனவே உள்ள எதுவும் மாறாது: அதே பெயருள்ள பொருள் அப்படியே இருக்கும். பின்னர்: Inventory இல் உங்கள் சொந்த விலைகளை அமையுங்கள் (மாதிரி விலைகள் பரிந்துரைகள் மட்டுமே), நீங்கள் வாங்குவதை Purchases இல் உள்ளிடுங்கள் (பொருட்கள் இருப்பில் வரும் வரை ஒவ்வொரு உணவும் மங்கலாகவே இருக்கும்), Production → Recipes இல் உங்கள் சமையல்காரருடன் சமையல் அளவுகளைச் சரிபாருங்கள், நீங்கள் பரிமாறாத உணவுகளை நீக்குங்கள்.
1
ஒவ்வொரு உணவையும் பானத்தையும் Inventory இல் Sell Price (GST க்கு முன்) உடன் சேருங்கள். அதன் Category மெனுப் பிரிவாகிறது: Main Course, Starters, Drinks… Sell Price உள்ள ஒவ்வொரு பொருளும் மெனுவில் தோன்றும்.
2
பொருட்களையும் (ingredients) பொருட்களாகச் சேருங்கள் (அரிசி, சிக்கன், எண்ணெய், டீத்தூள்), kg அல்லது litre போன்ற அலகுகளுடன், அவற்றை வழக்கம்போல் Purchases மூலம் வாங்குங்கள். பொருட்களுக்கு Sell Price இல்லை, எனவே அவை மெனுவில் வருவதில்லை.
3
உங்கள் சமையலறையில் சமைக்கும் ஒவ்வொரு உணவுக்கும் Inventory → 🏭 Production → 🧾 Recipes இல் ஒரு சமையல் குறிப்பு எழுதுங்கள் (அத்தியாயம் 8c பார்க்கவும்), Made to order டிக் செய்யுங்கள். உதாரணம்: ஒரு Chicken Biryani க்கு அரிசி 0.25 kg, சிக்கன் 0.2 kg. உணவு விற்கப்படும்போது அந்தப் பொருட்கள் இருப்பிலிருந்து குறையும்.
4
வாங்கி அப்படியே விற்கும் பொருட்களுக்கு (பாட்டில் தண்ணீர், குளிர்பானங்கள்) சமையல் குறிப்பு தேவையில்லை: அவற்றை Purchases மூலம் வாங்குங்கள், விற்கும்போது அவற்றின் சொந்த இருப்பு குறையும்.

உணவுகளும் பொருட்களும் எல்லாமே Inventory இல் உள்ள பொருட்கள்தான். அதன் பட்டியலில் Made to order உணவுக்குச் சொந்த இருப்பு இல்லாததால், இருப்பில் — உம் நிலையில் 🍳 Dish உம் தெரியும். ஒரு நேரத்தில் ஒரு வகையைப் பார்க்க, பட்டியலுக்கு மேலே உள்ள வடிகட்டியைப் பயன்படுத்துங்கள்: Items for sale (உங்கள் மெனு: Sell Price உள்ள அனைத்தும்) அல்லது Materials & ingredients (சமையல் குறிப்பில் பயன்படும் அனைத்தும்).

பொருட்கள் ஸ்டோரில் இருக்க வேண்டும்

ஸ்டோரில் ஒரு உணவின் பொருட்கள் போதுமான அளவு இருந்தால் மட்டுமே அந்த உணவு ஆர்டரில் எடுக்கப்படும். மற்ற மேசைகளில் ஏற்கனவே ஆர்டர் செய்த உணவுகள் எவ்வளவு பயன்படுத்தும் என்பதையும் Accelent கணக்கிடுகிறது, ஏனெனில் சமையலறை அவற்றைச் சமைத்துக்கொண்டிருக்கிறது. ஏதாவது குறைவாக இருந்தால், என்ன குறைகிறது என்று சொல்லும், உதாரணமாக Chicken: needs 0.6 kg, 0.4 kg in the store (சிக்கன் 0.6 kg தேவை, ஸ்டோரில் 0.4 kg உள்ளது), அந்த உணவின் பொத்தான் மங்கலாகும். Purchases மூலம் பொருட்களை வாங்கினால் உணவு மீண்டும் கிடைக்கும். Sales திரையில் அல்லது போனிலிருந்து உணவு விற்கப்படும்போதும் இதே சரிபார்ப்பு நடக்கும். ஒவ்வொரு உணவுப் பொத்தானும் ஸ்டோரிலிருந்து இன்னும் எத்தனை செய்ய முடியும் என்றும் காட்டும், உதா. 12 left; 5 அல்லது அதற்குக் குறைவாக இருந்தால் அதில் ⚠ வரும், பொத்தான் மீது மவுஸை வைத்தால் எந்தப் பொருள் குறைகிறது என்று தெரியும்.

💡 வாங்கி விற்கும் பொருளின் இருப்பு தீர்ந்தாலோ, இருப்பும் Made to order சமையல் குறிப்பும் இல்லாத உணவுக்கோ மெனுப் பொத்தான் மங்கலாகும். கொள்முதல்கள் உள்ளிடப்படும் முன்பே உங்கள் சமையலறை அடிக்கடி சமைத்தால், நிர்வாகி ⚙ Restaurant Settings இல் Don't take an order for a dish when the store hasn't enough of its ingredients டிக்கை நீக்கலாம்: அப்போது உணவுகள் எப்போதும் அனுமதிக்கப்படும், பொருட்களின் இருப்பு பூஜ்ஜியத்துக்குக் கீழே போகும், Low Stock Monitor மேலும் வாங்கச் சொல்லும்.

மேசைகள்

முதல் முறை ஆறு மேசைகள் (Table 1 முதல் Table 6 வரை) அமைக்கப்படுகின்றன. மேசைகளைச் சேர்க்க, பெயர் மாற்ற அல்லது நீக்க மற்றும் இருக்கைகளை அமைக்க 🪑 Tables… கிளிக் செய்யுங்கள் (உதா. Garden 1, Cabin A). ஒவ்வொரு மேசையும் ஒரு அட்டை:

  • காலியான மேசை சாதாரணமாக இருக்கும், அதன் இருக்கைகளையும் ✓ Free ஐயும் காட்டும்.
  • நடப்பு ஆர்டர் உள்ள மேசைக்கு வண்ண ஓரம் இருக்கும், அது தன் மொத்தத்தையும் எவ்வளவு நேரம் திறந்திருக்கிறது என்பதையும் காட்டும் (🕑 25 min, 🕑 1h 05m).
  • பணியாளர் அல்லது வாடிக்கையாளர் பில் கேட்கும்போது, மேசைக்கு மஞ்சள் (amber) ஓரம் வந்து 🧾 Bill asked காட்டும்.
  • நீங்கள் திறந்துள்ள மேசைக்குத் தடித்த ஓரம் இருக்கும்.

திரையின் கீழே உள்ள ஒரு விளக்கம் ஓரங்களின் பொருளைச் சொல்கிறது.

ஆர்டர் எடுத்தல்

1
மேசையைக் கிளிக் செய்யுங்கள், பின்னர் ஒரு மெனுப் பிரிவை, பின்னர் உணவுகளை. ஒவ்வொரு தட்டலும் ஒன்றைச் சேர்க்கும்; மீண்டும் தட்டினால் இன்னொன்று. உணவை விரைவாகக் கண்டுபிடிக்க Search the menu இல் தட்டச்சு செய்யுங்கள்.
2
ஆர்டரில் ஒரு வரியைத் தேர்ந்தெடுத்து, அளவை மாற்ற − / +, சமையலறைக்கான 📝 Note (காரம் குறைவு, வெங்காயம் வேண்டாம்), அல்லது ✕ Remove பயன்படுத்துங்கள். ஒரு வரியின் மீது மவுஸ் வீலைச் சுழற்றியும் அளவை மாற்றலாம்: மேலே சுழற்றினால் ஒன்று கூடும், கீழே சுழற்றினால் ஒன்று குறையும் (கீழே சுழற்றுவது 1 இலும், சமையலறைக்கு அனுப்பிய அளவிலும் நிற்கும்).

⚙ Restaurant Settings இல் Kitchen printer ஐத் தேர்ந்தெடுங்கள், உதாரணமாக சமையலறையில் உள்ள சிறிய தெர்மல் அச்சுப்பொறி. அப்போது PC யிலிருந்தும் பணியாளர்களின் போன்களிலிருந்தும் வரும் ஒவ்வொரு KOT உம் நேரடியாக அதில் அச்சாகும், பில்கள் உங்கள் சாதாரண அச்சுப்பொறியிலேயே அச்சாகும். சமையலறை அச்சுப்பொறி இல்லாவிட்டால், KOT அச்சிட முன்னோட்டமாகத் திறக்கும், அல்லது அந்தத் தேர்வை டிக் செய்தால் நேரடியாக Windows இன் இயல்புநிலை அச்சுப்பொறிக்குச் செல்லும்.

பணியாளர்களின் போன்கள்

பணியாளர்கள் Accelent செயலி மூலம் தங்கள் போன்களில் மேசையிலேயே ஆர்டர் எடுக்கலாம் (அத்தியாயம் 19 பார்க்கவும்). PC யின் Business Type Restaurant அல்லது Hotel ஆக இருக்கும்போது, செயலியின் டாஷ்போர்டில் 🍽 Restaurant தெரியும்:

  • ஒரு மேசையைத் தட்டுங்கள் (பிஸியானவை தங்கள் மொத்தத்தையும் நிமிடங்களையும் காட்டும்), அல்லது New Takeaway, அல்லது ஹோட்டலில் Room Service (விருந்தினர் தங்கியிருக்கும்போது மட்டும்).
  • Add Dishes மெனுவைப் பிரிவுவாரியாக, தேடலுடன் திறக்கிறது; ஒன்றைச் சேர்க்க உணவைத் தட்டுங்கள். − / + மூலம் அளவுகளை மாற்றுங்கள், சமையலறைக்குக் குறிப்பு கொடுக்க உணவைத் தட்டுங்கள்.
  • Send to Kitchen PC யில் KOT ஐ அச்சிடுகிறது (பணியாளரின் பெயருடன்). பின்னர் புதிதாக ஏதாவது சேர்க்கும் வரை பொத்தான் ✓ Sent to kitchen காட்டும்.
  • Ask for Bill கவுண்டருக்குச் சொல்கிறது: PC பீப் ஒலித்து, மேசை மற்றும் பணியாளருடன் ஒரு பட்டையைக் காட்டி, மேசையை 🧾 Bill asked எனக் குறிக்கிறது. காசாளர் மேசையைத் திறந்து 💵 Bill அழுத்துகிறார், அது பணத்தைப் பெறுகிறது.
  • ஹோட்டலில், Charge to Room ஆர்டரைத் தங்கியுள்ள விருந்தினரின் கணக்கில் சேர்க்கிறது.

PC யில் உள்ள அதே விதிகள் பொருந்தும்: உணவுக்கு அதன் பொருட்கள் ஸ்டோரில் இருக்க வேண்டும், சமையலறைக்குப் போன உணவை நிர்வாகி மட்டுமே நீக்கவோ ரத்து செய்யவோ முடியும். பணியாளர்களுக்கு Create sales அனுமதியும் போன் அணுகலும் தேவை (Settings → 👥 Users). ஒரு உரிமம் ஒரே நேரத்தில் குறிப்பிட்ட எண்ணிக்கையிலான போன் கணக்குகளை அனுமதிக்கிறது; அதனால் ஒரு பணியாளரின் போன் மறுக்கப்பட்டால், மேலும் சேர்க்க எங்களைத் தொடர்பு கொள்ளுங்கள். Create sales-க்குப் பதிலாக ஒரு வெயிட்டருக்கு Take table orders (Waiter டெம்ப்ளேட்) மட்டும் கொடுக்கலாம்: அவர்கள் ஆர்டர் எடுத்து சமையலறைக்கு அனுப்புவார்கள், ஆனால் பில் போடவோ, அறைக்குக் கட்டணம் சேர்க்கவோ, ஆர்டரை ரத்து செய்யவோ முடியாது.

மேசையில் QR மூலம் ஆர்டர்

DRV001, அத்தியாயம் 9d பார்க்கவும்) உள்ளிட்டு, Order தட்டி, அதைப் பின்தொடரலாம்: Received → Confirmed → Preparing (ready about …) → Served, மற்றும் Ask for Bill தட்டலாம்.

உணவக பில்களில் GST (இந்தியா)

உணவக பில் ஒரே உணவகச் சேவை, எனவே முழு பில்லுக்கும் ஒரே GST விகிதம். அதை ⚙ Restaurant Settings இல் தேர்ந்தெடுங்கள் (நிர்வாகி மட்டும்):

  • உள்ளீட்டு வரி வரவு இல்லாமல் 5%: உணவகங்கள், கஃபேக்கள், தாபாக்கள் மற்றும் டேக்அவே (வழக்கமான நிலை, இயல்புநிலையும் இதுவே).
  • உள்ளீட்டு வரி வரவுடன் 18%: specified premises ஆக உள்ள ஹோட்டலுக்குள் இருக்கும் உணவகம் (முந்தைய ஆண்டில் அறைகளுக்கு நாளொன்றுக்கு ₹7,500 க்கு மேல் வசூலித்த, அல்லது தன்னை அப்படி அறிவித்த ஹோட்டல்).

Rooms திரையைப் பயன்படுத்தும் ஹோட்டல் தேர்ந்தெடுக்க வேண்டியதில்லை: வளாகம் specified premises ஆக இருக்கும் ஆண்டில் Accelent உணவகத்தைத் தானாக 18% க்கு மாற்றுகிறது (அத்தியாயம் 9c பார்க்கவும்).

சொந்த உணவகத்துடனோ இல்லாமலோ, ஹோட்டல், லாட்ஜ் அல்லது விருந்தினர் இல்லத்துக்கு. ஒவ்வொரு விருந்தினரின் தங்குதலும் அவருடைய அறையில் ஒரு நடப்புக் கணக்கு: இரவுகள் தானாகக் கூடுகின்றன, கூடுதல் கட்டணங்களும் உங்கள் உணவகத்தின் உணவும் அதில் சேர்க்கப்படுகின்றன, செக்-அவுட்டில் விருந்தினருக்கு அனைத்துக்கும் ஒரே GST பில் கிடைக்கும், அதில் முன்பணம் கழிக்கப்படும்.

  • நிரம்பிய அறைக்கு வண்ண ஓரம் இருக்கும், விருந்தினரின் பெயரையும் இதுவரையிலான இரவுகளையும் காட்டும்.

விருந்தினரின் கணக்கு

இதுவரை வசூலித்த அனைத்தையும், GST மற்றும் இன்னும் செலுத்த வேண்டிய தொகையுடன் பார்க்க, நிரம்பிய அறையைக் கிளிக் செய்யுங்கள்:

  • அறை இரவுகள் செக்-இன் தேதியிலிருந்து தானாகக் கணக்கிடப்படுகின்றன. ₹ Night Rates ஒரு குறிப்பிட்ட இரவின் கட்டணத்தை மாற்றுகிறது (வார இறுதிக் கட்டணம், தள்ளுபடி).
  • ➕ Add Charge: கூடுதல் படுக்கை அல்லது முன்கூட்டிய செக்-இன்னுக்கு Part of the room தேர்ந்தெடுங்கள் (அந்த இரவின் அறை மதிப்பில் சேர்க்கப்படும்), அல்லது சலவை, போக்குவரத்து போன்றவற்றுக்கு அதன் சொந்த GST % உடன் Another service. ✕ Remove Charge தவறாகச் சேர்த்த கட்டணத்தை நீக்குகிறது.
  • 💵 Advance தங்குதலின்போது பெற்ற மேலும் பணத்தைப் பதிவு செய்கிறது. செக்-அவுட் பில் பெற்ற முன்பணத்தையும் செலுத்திய மீதியையும் காட்டும்; முன்பணம் பில்லை விட அதிகமாக இருந்தால், திருப்பிக் கொடுத்த தொகையைக் காட்டும், அது விருந்தினருக்குத் திருப்பிச் செலுத்தியதாகப் பதிவாகும்.
  • ⇄ Move Room விருந்தினரை ஒரு காலியான அறைக்கு மாற்றுகிறது; பழைய அறை சுத்தம் செய்யப் போகும்.
  • 🗑 Cancel Check-in தவறாகச் செய்த செக்-இன்னுக்கு: அறை காலியாகும், எந்த முன்பணமும் திருப்பிச் செலுத்தியதாகப் பதிவாகும்.

(🛏 Charge to Room பொத்தானும் இதையே செய்கிறது.)

உணவு உணவகத்தின் GST விகிதத்தில் விருந்தினரின் கணக்கில் சேர்கிறது, அதன் பொருட்கள் (அல்லது அதன் சொந்த இருப்பு) உடனே ஸ்டோரிலிருந்து குறைகின்றன, செக்-அவுட்டில் செலுத்தப்படுகிறது.

  • ஒரு தங்குதல் அல்லது பில்லுக்கு அதிகபட்சக் கமிஷன்: ஒரு பாதுகாப்பு வரம்பு, அதனால் தட்டச்சுப் பிழை (5% க்குப் பதிலாக 50%) பெரும் தொகையைக் கொடுத்துவிட முடியாது.
  • கமிஷனில் TDS (நீங்கள் இயக்கும் வரை அணைக்கப்பட்டிருக்கும்): விகிதம் (2%, அல்லது PAN இல்லாமல் 20%) மற்றும் TDS பொருந்தும் முன் ஒரு கூட்டாளி சம்பாதிக்கக்கூடிய ஆண்டுத் தொகை (₹20,000). நிறுவனம் அல்லது நிறுவனக் கூட்டு கமிஷனில் TDS பிடிக்க வேண்டும்; தனிநபர் அல்லது HUF, கடந்த ஆண்டு வணிக வருவாய் ₹1 கோடிக்கு மேல் (தொழிலுக்கு ₹50 லட்சம்) இருந்தால் மட்டுமே. நீங்கள் பிடிக்க வேண்டுமா என்று உங்கள் கணக்காளரிடம் கேளுங்கள். பிடித்த TDS அரசுக்குச் செலுத்தும் வரை TDS on commission (payable) கணக்கில் தர வேண்டியதாகக் காட்டப்படும்.

கூட்டாளிவாரி வணிகம்

📊 Business by Partner டேப் எந்தத் தேதிகளுக்கும், ஒவ்வொரு கூட்டாளியும் எத்தனை பில்கள் கொண்டுவந்தார், வணிகம் (அறை வாடகை மற்றும் உணவு) மற்றும் அவர்களின் கமிஷன், நீங்கள் செலுத்தியது மற்றும் இன்னும் தர வேண்டியது ஆகியவற்றைப் பெரியது முதலில் காட்டுகிறது.

💡 Partners திரையைப் பயன்படுத்த ஊழியர்களுக்கு Expenses அனுமதி தேவை. செக்-இன் அல்லது பில்லில் கூட்டாளியைத் தேர்ந்தெடுக்க Rooms அல்லது Restaurant திரை மட்டுமே தேவை.
அத்தியாயம் 9e — ஹவுஸ்கீப்பிங் ஹோட்டல்கள், லாட்ஜ்கள் மற்றும் விருந்தினர் இல்லங்களுக்கு

9e. ஹவுஸ்கீப்பிங் (அறைச் சுத்தம் மற்றும் சலவை)

🧹 Housekeeping திரை (FINANCE இன் கீழ், ஹோட்டலுக்கு) உங்கள் ஊழியர்களுக்கான சுத்தம் மற்றும் சலவை வேலைகளைப் பட்டியலிடுகிறது. பெரும்பாலான வேலைகள் தானாகவே தோன்றும்:

  • செக்-அவுட் ஒரு Clean the room வேலையை உருவாக்குகிறது. அது முடிந்ததும், அறை அடுத்த விருந்தினருக்குத் தானாக Ready ஆகிறது (Rooms திரையில் ✨ Room Is Ready அழுத்தினாலும் அது முடியும்).
  • ஒவ்வொரு காலையும் நீங்கள் அமைத்த நேரத்தில், நிரம்பிய ஒவ்வொரு அறைக்கும் ஒரு Daily cleaning வேலை உருவாகிறது.
  • விருந்தினர்கள் அறை QR அட்டையில் 🧹 Clean my room அல்லது 👕 Laundry pickup தட்டலாம் (QR ordering இயக்கத்தில் இருக்கும்போது). PC பீப் ஒலித்து கோரிக்கையை மேலே காட்டும். ஒரு தினசரிச் சுத்தம் காத்திருந்தால், விருந்தினரின் கோரிக்கை அதன் இடத்தைப் பிடிக்கும்.
  • முன் மேசை ➕ New Task மூலம் எந்த வேலையையும் சேர்க்கலாம்.

யார் செய்கிறார்கள்

⚙ Housekeeping Settings (நிர்வாகி) இல் பணியில் உள்ள ஊழியர்களைத் டிக் செய்யுங்கள் (முதலில் அவர்களை 👥 Employees இல் சேருங்கள்). ஒவ்வொரு புதிய வேலையும் மிகக் குறைவான திறந்த வேலைகள் உள்ளவருக்குச் செல்கிறது; 👤 Give to… அதை மாற்றுகிறது. சுத்தம் செய்யக் காத்திருக்கும் அறையை யார் சுத்தம் செய்கிறார் என்று Rooms திரை காட்டுகிறது.

வேலையைச் செய்தல்

1
வேலையைத் தேர்ந்தெடுத்து ▶ Start (விருப்பத்திற்குரியது), முடிந்ததும் ✓ Done கிளிக் செய்யுங்கள். ✕ Cancel task தேவையில்லாத வேலையை நீக்குகிறது.
2
சலவை: அறையிலிருந்து துணிகள் எடுக்கப்படும்போது 👕 Collected கிளிக் செய்யுங்கள். அவை திரும்பி வரும்போது, ✓ Laundry returned… கிளிக் செய்து ஒவ்வொரு வகையிலும் எத்தனை துண்டுகள் என்று உள்ளிடுங்கள். மொத்தம் சலவை GST உடன் விருந்தினரின் அறை பில்லில் சேர்கிறது (நீங்கள் மாற்றாத வரை 18%).
💡 சலவை விலைப் பட்டியல் (சட்டை, கால்சட்டை, புடவை…), சலவைக்கான GST மற்றும் தினசரிச் சுத்தத்தின் நேரம் ⚙ Housekeeping Settings இல் உள்ளன. ✓ Done today டேப் இன்று முடிந்த வேலைகள், யார் செய்தார்கள், வசூலித்த சலவைக் கட்டணம் ஆகியவற்றைப் பட்டியலிடுகிறது.
அத்தியாயம் 10 — கொள்முதல்

10. கொள்முதல் பேனல்

சப்ளையர்களிடமிருந்து வரும் ஒவ்வொரு கொள்முதல் பில்லையும் இங்கே பதிவு செய்யுங்கள். இருப்பு உயரும், சப்ளையருக்குச் செலுத்த வேண்டிய நிலுவை தானாகக் கண்காணிக்கப்படும்.

கொள்முதலைப் பதிவு செய்தல்

1
+ New Purchase கிளிக் செய்யுங்கள்.
2
முதலில் Vendor Name ஐத் தேர்ந்தெடுங்கள் அல்லது தட்டச்சு செய்யுங்கள் — அதற்குக் கீழே உள்ள அனைத்தும் இதைப் பொறுத்தது. ஏற்கனவே உள்ள சப்ளையருக்கு முகவரி/போன்/GSTIN தானாக நிரம்பும், அவருடைய வழக்கமான பொருட்கள் நேரடியாக Order Items அட்டவணையில் ஏறும், ஒவ்வொன்றும் முன்கூட்டியே டிக் செய்யப்பட்டுத் தயாராக இருக்கும்.
3
இந்த பில்லில் சேர்க்க வேண்டாத எந்த வரிசையின் (☑) டிக்கையும் நீக்குங்கள். தேவைக்கேற்ப ஒவ்வொரு வரிசையின் Qty/Rate/GST% ஐ மாற்றுங்கள் — Amount உம் கீழே உள்ள Subtotal/GST/Grand Total உம் உடனுக்குடன் மாறும்.
4
அட்டவணையில் ஏற்கனவே இல்லாதவற்றை ஸ்கேன் செய்து சேருங்கள் (Order Items இன் மேலே 📷 புலம் + 📱 Scan with Phone), அல்லது அட்டவணைக்குக் கீழே ➕ Add Item to Same Vendor மூலம் முற்றிலும் புதிய பொருளைப் பதிவு செய்யுங்கள்.
5
Bill Details இல் Bill Number, Bill Date மற்றும் Payment Method (Cash / Bank Transfer / Cheque / Card / UPI / Credit to Vendor) நிரப்புங்கள்.
6
💾 Save Purchase கிளிக் செய்யுங்கள். இருப்பும் சப்ளையரின் நிலுவையும் உடனே மாறும். அதே பொருட்களும் மொத்தமும் கொண்ட பில் 60 நாட்களுக்குள் (எந்த சப்ளையரின் கீழும்) ஏற்கனவே சேமிக்கப்பட்டிருந்தால், இரண்டாவது முறை சேமிக்கும் முன் Accelent கேட்கும்.
💡 பில்லைத் திருத்துதல் அல்லது நீக்குதல்: பில்கள் பட்டியலில் அதைத் தேர்ந்தெடுத்து ✏️ Edit Bill அல்லது ❌ Delete Bill கிளிக் செய்யுங்கள். திருத்தம் இருப்பையும் சப்ளையரின் கணக்கையும் திருத்திய பில்லுக்கு ஏற்ப மாற்றும். தவறான சப்ளையரின் கீழ் சேமித்த பில்லை நீக்கி, சரியானவரின் கீழ் மீண்டும் உள்ளிடுவதே சிறந்தது — நீக்குவது அதன் இருப்பு, கணக்குப் பதிவு மற்றும் GST ஐத் திருப்புகிறது, ஒரு நகலை Deletion Watcher இல் வைக்கிறது. நீக்கிய பிறகு, இப்போது வேறு எங்கும் பயன்படாத பில்லின் பொருட்களை அதே படியில் நீக்க Accelent முன்வரும். பொருட்கள் ஏற்கனவே விற்கப்பட்ட பில்லை நீக்க முடியாது; அதை Edit Bill மூலம் திருத்துங்கள், அல்லது திருப்பி அனுப்பிய பொருட்களை Returns → Purchase Returns இல் பதிவு செய்யுங்கள்.

சப்ளையர் மற்றும் பொருள் சேர்க்கைகள்

சப்ளையரும் நீங்கள் வாங்கும் பொருளும் Accelent இல் ஏற்கனவே உள்ளனவா என்பதைப் பொறுத்து, Order Items அட்டவணையும் ➕ Add Item to Same Vendor பேனலும் நான்கு நிலைகளுக்கு ஏற்ப மாறுகின்றன. Vendor Name புலமே அதற்குக் கீழே என்ன தெரியும் என்பதை எப்போதும் தீர்மானிக்கிறது, எனவே முதலில் சப்ளையரைத் தேர்ந்தெடுங்கள் அல்லது தட்டச்சு செய்யுங்கள்.

1. பழைய சப்ளையர் + பழைய பொருள்

1
Vendor Name இல் சப்ளையரின் பெயரைத் தட்டச்சு செய்யத் தொடங்கி டிராப்டவுனிலிருந்து தேர்ந்தெடுங்கள். அவருடைய முகவரி, போன் மற்றும் GSTIN தானாக நிரம்பும்.
2
இந்த சப்ளையரிடம் முன்பு வாங்கிய அனைத்தும் Order Items அட்டவணையில் தானாக நிரம்பும், ஒவ்வொரு வரிசையும் டிக் செய்யப்பட்டிருக்கும். இந்த முறை வாங்காதவற்றின் டிக்கை நீக்குங்கள் — வேண்டுமென்றே நீக்கும் பொத்தான் இல்லை, அதனால் அட்டவணையிலிருந்து எதுவும் தவறுதலாகச் சரக்கிலிருந்து நீங்காது.
3
நீங்கள் வாங்குபவற்றின் Qty ஐ மாற்றி, சேமியுங்கள்.

2. பழைய சப்ளையர் + புதிய பொருள்

1
மேலே உள்ளபடி பழைய சப்ளையரைத் தேர்ந்தெடுங்கள்.
2
➕ Add Item to Same Vendor இல் Name, Category, Buy Rate, GST%, Sell Price மற்றும் Qty நிரப்புங்கள். தானியங்கிப் பொருள் குறியீட்டுக்கு Code க்கு அருகில் 🔍 Generate கிளிக் செய்யுங்கள், அல்லது உங்களுடையதைத் தட்டச்சு செய்யுங்கள்.
3
✅ Add Item to Purchase கிளிக் செய்யுங்கள். பொருள் உருவாக்கப்பட்டு, இந்த சப்ளையருடன் இணைக்கப்பட்டு, Order Items அட்டவணையில் சேர்க்கப்படும்.

3. புதிய சப்ளையர் + புதிய பொருள்

1

Scan Vendor Bill க்கு ஒவ்வொரு நிறுவலிலும் சேர்க்கப்படாத உள்ளூர் AI கூறுகள் தேவை; அது கிடைக்கவில்லை என்று சொன்னால், Accelent இன் மற்ற எதுவும் பாதிக்கப்படாது.
💡 வேகம்: 8 GB RAM உள்ள PC யில் ஸ்கேன் விரைவாக முடியும்; 4 GB இல் இன்னும் வேலை செய்யும், ஆனால் அதிக நேரம் ஆகும் — இயங்க விடுங்கள். இலவச சோதனை: 15 பில் ஸ்கேன்கள் சேர்க்கப்பட்டுள்ளன; அதன் பிறகு ஸ்கேனிங்கிற்குச் செயல்படுத்திய உரிமம் தேவை (சோதனையின் மீதிக் காலத்துக்கு மற்ற அனைத்தும் தொடர்ந்து இயங்கும்). சந்தாவுடன் ஸ்கேனிங் வரம்பற்றது.

கொள்முதல் திருப்பம்

சப்ளையருக்குத் திருப்பி அனுப்பிய பொருட்களைப் பதிவு செய்ய Returns பேனல் → Purchase Returns டேபுக்குச் செல்லுங்கள். டெபிட் நோட் உருவாகும், இருப்பு குறையும். திருப்பத் தொகை Profit & Loss, Trading Account மற்றும் Balance Sheet அறிக்கைகளில் உங்கள் கொள்முதல் தொகையிலிருந்தும் கழிக்கப்படும்.

💡 கொள்முதலைப் பதிவு செய்யும்போது எப்போதும் சப்ளையரின் பில் எண்ணை உள்ளிடுங்கள் — குறிப்பிட்ட கொள்முதல்களைக் கண்டுபிடிப்பதை இது எளிதாக்குகிறது, GST சரிபார்ப்புக்கு இது தேவை.
அத்தியாயம் 11 — செலவுகள் மற்றும் ரசீதுகள்

11. செலவுகள் மற்றும் ரசீதுகள்

செலவுகள் பேனல்

எல்லா வணிகச் செலவுகளையும் இங்கே பதிவு செய்யுங்கள்: வாடகை, மின்சாரம், சம்பள முன்பணம், போக்குவரத்து, அலுவலகப் பொருட்கள் போன்றவை.

1
+ Add Expense கிளிக் செய்யுங்கள்.
2
Category (Rent / Electricity / Salary / Transport / Other) தேர்ந்தெடுத்து, தொகை, பணம் செலுத்தும் முறை (Cash அல்லது Bank) மற்றும் ஒரு சிறு விவரத்தை உள்ளிடுங்கள்.
3
Save கிளிக் செய்யுங்கள். ரொக்கம் அல்லது வங்கி நிலுவை அதற்கேற்பக் குறையும்.

தொடர் செலவுகள்

ஒரு அட்டவணைப்படி மீண்டும் வரும் செலவுகளுக்கு (மாத வாடகை, மின்/நீர் கட்டணங்கள்), Recurring Expenses பேனலைப் பயன்படுத்துங்கள்:

1
Recurring Expenses க்குச் சென்று → + New Template கிளிக் செய்யுங்கள்.
2
செலவின் பெயர், தொகை, வகை மற்றும் மீண்டும் வரும் அட்டவணையை (மாதாந்திரம், வாராந்திரம் போன்றவை) அமையுங்கள்.
3
நேரம் வரும்போது Accelent நினைவூட்டும், செலவைத் தானாகப் பதிவு செய்யவும் முடியும்.

ரசீதுகள் பேனல்

Receipts பேனல் பெற்ற மற்றும் செலுத்திய எல்லாப் பணத்தின் லெட்ஜர் — வசூலித்த ரொக்கம், சப்ளையர்களுக்குச் செலுத்தியது, வங்கிப் பரிமாற்றங்கள் மற்றும் சம்பளம். இது விற்பனை, கொள்முதல் மற்றும் செலவுகளிலிருந்து தானாக நிரம்புகிறது. இங்கே தனி ரசீதையும் பதிவு செய்யலாம் (உதா. கடன் வாடிக்கையாளர் தன் நிலுவையைச் செலுத்தும்போது).

💡 கடன் வாடிக்கையாளர் உங்களுக்குப் பணம் செலுத்தும்போது, Receipts → + New Receipt க்குச் சென்று, வாடிக்கையாளரைத் தேர்ந்தெடுத்து, பெற்ற தொகையை உள்ளிடுங்கள். அவருடைய நிலுவை தானாகக் குறையும்.
அத்தியாயம் 12 — கணக்குகள் மற்றும் பரிமாற்றங்கள்

12. கணக்குகள் மற்றும் பரிமாற்றங்கள்

கணக்குகள் பேனல்

உங்கள் எல்லாப் பணக் கணக்குகளையும் காட்டுகிறது — Cash, மற்றும் ஒவ்வொரு வங்கிக் கணக்கும். ஒவ்வொரு கணக்குக்கும் நீங்கள் பார்க்கலாம்:

  • தற்போதைய நிலுவை (எப்போதும் புதியது)
  • தேதிகள் மற்றும் விவரங்களுடன் முழுப் பரிவர்த்தனை வரலாறு
  • டெபிட் (வந்த பணம்) மற்றும் கிரெடிட் (போன பணம்) நெடுவரிசைகள்

வாடிக்கையாளர் கடன் அறிக்கை

Accounts → Credit Manager → Customer Statement க்குச் சென்று, வாடிக்கையாளரின் பெயரின் எந்தப் பகுதியையும் தட்டச்சு செய்து (தட்டச்சு செய்யும்போதே பரிந்துரைகள் வரும்) Show Statement அல்லது Enter அழுத்துங்கள். அறிக்கை மொத்தக் கடன், செலுத்திய தொகை மற்றும் இன்னும் நிலுவையில் உள்ளது, ஒவ்வொரு கடன் இன்வாய்ஸும், ஒவ்வொரு இன்வாய்ஸிலும் கடனில் எடுத்த பொருட்கள், பெற்ற ஒவ்வொரு பணம் ஆகியவற்றைக் காட்டுகிறது. Print வாடிக்கையாளருக்காக அதே அறிக்கையை A4 இல் தருகிறது. ஹோட்டல் அல்லது உணவகத்தின் கடன் பில் அது எதற்கானது என்பதைக் காட்டும் (விருந்தினர், அறை மற்றும் தங்கிய தேதிகள், அல்லது டேபிள்); தங்குதலின் முன்பணம் ஏற்கனவே செலுத்தப்பட்டதாகக் காட்டப்படும், எனவே ஸ்டேட்மென்டை அச்சிட்டு பயண முகவரிடம் சான்றாகக் கொடுக்கலாம். பணம் வங்கிப் பரிமாற்றம், UPI, கார்டு அல்லது காசோலையில் வந்தால், பணம் செலுத்தும் சாளரத்தில் Into bank தேர்ந்தெடுக்கவும்.

வங்கிக் கணக்கைச் சேர்த்தல்

1
Accounts க்குச் சென்று → Bank Accounts இன் கீழ் ➕ Add New Bank கிளிக் செய்யுங்கள்.
2
வங்கியின் பெயர், கணக்கு எண் மற்றும் தொடக்க நிலுவையை (உங்கள் தொடக்கத் தேதியின் வங்கி அறிக்கையிலிருந்து) உள்ளிடுங்கள்.
3
Save கிளிக் செய்யுங்கள். இப்போது வங்கிக் கணக்கு எல்லாப் பணம் செலுத்தும் டிராப்டவுன்களிலும் (Sales, Purchases, Expenses) தெரியும்.

பரிமாற்றங்கள் பேனல்

உங்கள் சொந்தக் கணக்குகளுக்கு இடையே பணத்தை நகர்த்தும்போது — உதாரணமாக ரொக்கத்தை வங்கியில் டெபாசிட் செய்தல், அல்லது இரண்டு வங்கிக் கணக்குகளுக்கு இடையே பரிமாற்றம் — Transfers பேனலைப் பயன்படுத்துங்கள்.

1
Transfers க்குச் செல்லுங்கள். Inter-Accounts Transfer இல் Paid From (உதா. Cash in Hand) மற்றும் Received In (உதா. HDFC Bank) தேர்ந்தெடுங்கள் — ஒவ்வொன்றின் கிடைக்கும் நிலுவையும் அருகில் காட்டப்படும்.
2
தொகையையும் தேதியையும், விரும்பினால் Reference மற்றும் Description ஐயும் உள்ளிடுங்கள்.
3
Add Transfer கிளிக் செய்யுங்கள். ரொக்கம் குறையும், வங்கி உயரும் — இரண்டு நிலுவைகளும் மாறும். இது Recent Transfers இல் தெரியும்.

பழைய பரிமாற்றங்களைத் தேதி மற்றும் கணக்கால் கண்டுபிடிக்க வலப்புறம் உள்ள Transfer History Search ஐயும், அச்சிட Print Report ஐயும் பயன்படுத்துங்கள்.

⚠ வங்கி டெபாசிட்டை ஒருபோதும் "வருமானம்" அல்லது "ரசீது" ஆகப் பதிவு செய்ய வேண்டாம் — எப்போதும் Transfers பேனலைப் பயன்படுத்துங்கள். வேறு எங்காவது பதிவு செய்தால் உங்கள் வருமான எண்ணிக்கைகள் உயர்ந்துவிடும்.

13. அறிக்கைகள், தரவு ஒப்பீடு மற்றும் Aging அறிக்கை

தரவு ஒப்பீடு (Reports) பேனல்

நிதிச் சுருக்கங்களையும் ஒப்பீடுகளையும் உருவாக்குகிறது:

  • Monthly Sales vs Purchases — ஒவ்வொரு மாதத்தின் மொத்தங்களைக் காட்டும் பார் வரைபடமும் அட்டவணையும்
  • Net Profit — விற்பனையிலிருந்து கொள்முதலும் செலவுகளும் கழித்து
  • Party Statement — உங்களுக்கும் எந்தத் தரப்பினருக்கும் இடையிலான முழுப் பரிவர்த்தனை வரலாறு
  • Account Statement — ஒரு குறிப்பிட்ட ரொக்கம் அல்லது வங்கிக் கணக்கின் எல்லாப் பரிவர்த்தனைகளும்

அறிக்கையைக் கோப்பாகச் சேமிக்க Export (Ctrl+E) பொத்தானையும், நேரடியாக அச்சிட Print (Ctrl+P) ஐயும் பயன்படுத்துங்கள்.

Aging அறிக்கை பேனல்

உங்கள் வாடிக்கையாளர்களின் நிலுவை இன்வாய்ஸ்கள் எவ்வளவு காலமாகச் செலுத்தப்படவில்லை, உங்கள் சப்ளையர் பில்கள் எவ்வளவு காலமாக நிலுவையில் உள்ளன என்று Aging அறிக்கை காட்டுகிறது.

காலப் பிரிவுபொருள்
0–30 நாட்கள்சமீபத்தியது — சாதாரணக் கடன் காலம்
31–60 நாட்கள்பழையதாகிறது — நினைவூட்டல் பரிந்துரைக்கப்படுகிறது
61–90 நாட்கள்காலம் கடந்தது — தரப்பினரைத் தொடர்பு கொள்ளுங்கள்
90+ நாட்கள்மிகவும் காலம் கடந்தது — தீவிரப்படுத்துங்கள் அல்லது வாராக்கடனாக எழுதுங்கள்

Finalization பேனல்

நிதியாண்டின் இறுதியில், உங்கள் Profit & Loss Statement மற்றும் Balance Sheet உருவாக்க Finalization க்குச் செல்லுங்கள். இந்த அறிக்கைகளை உங்கள் கணக்காளர் அல்லது தணிக்கையாளருக்காக அச்சிடலாம் அல்லது ஏற்றுமதி செய்யலாம்.

Finalization நிதியாண்டையும் மூடுகிறது. முந்தைய ஆண்டைப் பார்க்க, சாளரத்தின் கீழே உள்ள நிலைப்பட்டையிலிருந்து நிதியாண்டை மாற்றுங்கள்.

14. ஊழியர்கள் மற்றும் சம்பளம்

Accelent உங்கள் ஊழியர்களின் பதிவுகளை வைத்திருக்கிறது, வருகை, கூடுதல் நேரம் மற்றும் முன்பணங்களிலிருந்து ஒவ்வொரு மாதச் சம்பளத்தையும் கணக்கிடுகிறது, Cash அல்லது வங்கிக் கணக்கிலிருந்து செலுத்துகிறது, ஒவ்வொரு ஊழியருக்கும் சம்பளச் சீட்டு தருகிறது — அச்சாக அல்லது WhatsApp இல். கீழே உள்ள படிகள் ஒரு மாதத்தைத் தொடக்கம் முதல் இறுதி வரை பின்தொடர்கின்றன.

Accelent சம்பளத்தை எப்படிக் கணக்கிடுகிறது

ஒவ்வொரு ஊழியருக்கும் ஒரு சம்பள வகை உண்டு. நீங்கள் உள்ளிடும் Amount ஒவ்வொன்றுக்கும் வேறு பொருள் தருகிறது:

சம்பள வகைAmount இன் பொருள்மாதச் சம்பளம்
Fixedஒரு மாதத்துக்குமாதச் சம்பளம் ÷ வேலை நாட்கள் × வேலை செய்த நாட்கள்
Dailyஒரு நாளுக்குதினக்கூலி × வேலை செய்த நாட்கள்
Hourlyஒரு மணிக்குமணிக்கூலி × ஒரு நாளின் வேலை நேரம் × வேலை செய்த நாட்கள்
Pieceஒரு துண்டுக்கு (அல்லது உங்கள் அலகுக்கு)தயாரித்த அலகுகள் × ஒரு அலகுக்கான விகிதம்

வேலை செய்த நாட்கள் = வருகை − விடுப்புகள். கூடுதல் நேரம் (Fixed, Daily, Hourly) = மணிநேர விகிதம் × கூடுதல் மணிநேரம் × கூடுதல் நேரப் பெருக்கி (உதா. 1.5). நிகரச் சம்பளம் = அடிப்படைச் சம்பளம் + கூடுதல் நேரம் − வசூலித்த முன்பணங்கள். ஊழியர் சேர்ந்த மாதம் சேர்ந்த தேதியிலிருந்து கணக்கிடப்படுகிறது.

சம்பளத் தாள்

ஒரு ஊழியரைத் தேர்ந்தெடுத்து 📊 Salary Spreadsheet கிளிக் செய்யுங்கள். ஊழியர் சேர்ந்ததிலிருந்து ஒவ்வொரு முடிந்த மாதத்தையும் அது பட்டியலிடுகிறது — நடப்பு மாதம் முடிந்ததும் தோன்றும். ஒவ்வொரு மாதத்துக்கும் Attendance, Leaves, OT Hours, Advances மற்றும் துண்டு வேலையாட்களுக்கு Units ஐ மாற்றலாம்; Base Pay, OT Pay, Gross மற்றும் Net Payable தட்டச்சு செய்யும்போதே மாறும். Status நெடுவரிசை ⏳ Pending, 📝 Saved, not paid, அல்லது ✅ Paid காட்டும்.

1
💾 Save (not paid yet) எதையும் செலுத்தாமல் நீங்கள் உள்ளிட்டதை வைத்திருக்கிறது. மாதத்தின்போது இதைப் பயன்படுத்துங்கள்; அடுத்த முறை தாள் உங்கள் பதிவுகளைக் காட்டும். சேமிக்காத மாற்றங்களுடன் தாளை மூடினால், Accelent முதலில் கேட்கும்.
2
செலுத்தும் முன் சரிபாருங்கள்: மாதத்தைத் தேர்ந்தெடுத்து 🖨 Payslip கிளிக் செய்யுங்கள். இன்னும் செலுத்தாத மாதத்துக்கு ஒரு சாம்பல் நிற DRAFT சீட்டு கிடைக்கும் (Not paid yet எனக் குறிக்கப்பட்டு, கையொப்பம் அல்லது முத்திரை இல்லாமல்), ஊழியருடன் எண்ணிக்கைகளை ஒப்புக்கொள்ள.
3
💰 Pay Salary இன்னும் செலுத்தாத ஒவ்வொரு மாதத்தையும் செலுத்துகிறது: Cash அல்லது வங்கிக் கணக்கைத் தேர்ந்தெடுங்கள், ஒவ்வொரு மாதமும் கணக்குகளில் பதிவாகி ✅ Paid எனக் குறிக்கப்படும். சம்பளம் இல்லாத மாதம் (உதாரணமாக அலகுகள் உள்ளிடாத துண்டு வேலை) நீங்கள் சொன்னால் மட்டுமே செலுத்தப்படும்; இல்லையென்றால் நிலுவையில் இருக்கும்.
4
செலுத்திய உடனே, Accelent கடைசி மாதத்தின் சீட்டை வழங்கும்: 📄 Send on WhatsApp, 🖨 View / Print அல்லது Later.

அத்தியாயம் 15 — GST ரிட்டர்ன் மற்றும் இ-இன்வாய்ஸ்

15. GST ரிட்டர்ன் மற்றும் இ-இன்வாய்ஸ் (IRN)

GST ரிட்டர்ன் பேனல்

உங்கள் விற்பனை மற்றும் கொள்முதல் தரவை GST விவரங்களுடன் சுருக்கி, மாதாந்திர GST ரிட்டர்ன்களை (GSTR-1, GSTR-3B) தயாரிக்க இந்தப் பேனல் உதவுகிறது.

  • GSTR-1 — வெளிச்செல்லும் விநியோகங்கள் (உங்கள் விற்பனை) — அடுத்த மாதம் 11 ஆம் தேதிக்குள் தாக்கல் செய்யப்படும்
  • GSTR-3B — செலுத்த வேண்டிய வரியுடன் விற்பனை மற்றும் கொள்முதலின் சுருக்க ரிட்டர்ன் — 20 ஆம் தேதிக்குள் தாக்கல் செய்யப்படும்
  • GSTR-2B சரிபார்ப்பு — உங்கள் கொள்முதல் பில்களை உங்கள் சப்ளையர்களின் GSTR-2B உடன் ஒப்பிடுகிறது, அதனால் அவர்கள் தெரிவித்த உள்ளீட்டு வரி வரவை மட்டுமே நீங்கள் கோருவீர்கள்

உங்கள் சரக்குப் பொருட்களுக்கு ஒதுக்கிய HSN குறியீடுகளிலிருந்து Accelent CGST, SGST மற்றும் IGST ஐக் கணக்கிடுகிறது. Inventory பேனலில் எல்லாப் பொருட்களுக்கும் சரியான HSN குறியீடும் GST விகிதமும் ஒதுக்கப்பட்டுள்ளதா என்று உறுதி செய்யுங்கள்.

  • போன் பதிவுகள் சேர்க்கப்படுகின்றன: போனில் செய்த விற்பனையும் கொள்முதலும் வெளியீட்டு வரி, உள்ளீட்டு வரி வரவு மற்றும் GST சுருக்கத்தில், டெஸ்க்டாப் பதிவுகளைப் போலவே கணக்கிடப்படுகின்றன. போன் பதிவுகள் உங்கள் சொந்த மாநிலத்துக்குள் என்று கருதப்படுகின்றன (CGST + SGST).
  • HSN குறியீடுகள்: GSTR-1 HSN சுருக்கம் விற்பனையை ஒவ்வொரு பொருளின் உண்மையான HSN குறியீட்டின்படி குழுவாக்குகிறது. GSTR-1 ஏற்றுமதிக்கு முன், HSN குறியீடு இல்லாத விற்ற பொருட்களை Accelent பட்டியலிடுகிறது — முதலில் அவற்றை Inventory இல் சேர்த்து, பின்னர் மீண்டும் ஏற்றுமதி செய்யுங்கள்.
  • நீக்கிய அல்லது திருத்திய பில்கள்: பில்லை நீக்கினால் அதன் வரி GST ரிட்டர்னிலிருந்து நீங்கும், விற்பனையைத் திருத்தினால் இரண்டாவது பதிவு சேர்க்கப்படாமல் அதன் வரிப் பதிவு மாற்றப்படும்.

இ-இன்வாய்ஸ் / IRN பேனல்

அரசு வரம்புக்கு மேல் ஆண்டு வருவாய் உள்ள வணிகங்கள் ஒவ்வொரு B2B இன்வாய்ஸுக்கும் NIC இ-இன்வாய்ஸ் போர்ட்டல் மூலம் IRN (Invoice Reference Number) உருவாக்க வேண்டும்.

1
E-Invoice பேனலுக்குச் செல்லுங்கள்.
2
பட்டியலிலிருந்து இன்வாய்ஸைத் தேர்ந்தெடுத்து Generate IRN கிளிக் செய்யுங்கள்.
3
Accelent NIC க்கு ஏற்ற JSON கோப்பை உருவாக்குகிறது. IRN மற்றும் QR குறியீட்டைப் பெற அதை இ-இன்வாய்ஸ் போர்ட்டலில் சமர்ப்பியுங்கள்.
4
IRN இன்வாய்ஸுடன் சேமிக்கப்பட்டு இன்வாய்ஸ் நகலில் அச்சாகும்.
⚠ உங்களுக்கு இ-இன்வாய்ஸ் பொருந்தும் வரம்பையும் கடைசித் தேதிகளையும் உறுதிப்படுத்த உங்கள் CA அல்லது வரி ஆலோசகரைக் கலந்தாலோசியுங்கள். விதிகள் அவ்வப்போது மாறுகின்றன.

Business Type மெனுவின் திரைகளைத் தேர்ந்தெடுக்கிறது: Restaurant க்கு Sales, Returns, Aging Report மற்றும் E-Invoice க்குப் பதிலாக 🍽 Restaurant திரை கிடைக்கும் (அத்தியாயம் 9b பார்க்கவும்), Hotel, lodge or guest house க்கு 🛏 Rooms உம் கிடைக்கும் (அத்தியாயம் 9c பார்க்கவும்); Accelent ஐ மீண்டும் திறந்த பின் மாற்றம் தெரியும்.
👥 Usersஊழியர் கணக்குகளை உருவாக்குங்கள், ஒவ்வொருவரும் என்ன பார்க்கலாம் செய்யலாம் என்று தேர்ந்தெடுங்கள் (🔐 Permissions), போன் செயலியை யார் பயன்படுத்தலாம் என்று தீர்மானியுங்கள். நிர்வாகி கணக்கே முதன்மையானது — அதன் கடவுச்சொல்லைப் பாதுகாப்பாக வையுங்கள்.

🔒 Deletion Watcher ஏன் பூட்டப்பட்டுள்ளது?

Deletion Watcher டேப் ஒரு மிக முக்கியக் காரணத்துக்காக PIN / நிர்வாகி அங்கீகாரம் மூலம் பாதுகாக்கப்படுகிறது: அதில் நீக்கிய எந்தப் பதிவையும் மீட்டெடுக்கும் திறன் உள்ளது — இன்வாய்ஸ்கள், கொள்முதல்கள், செலவுகள், சரக்குப் பொருட்கள் மற்றும் பல.

இது எல்லா ஊழியர்களுக்கும் திறந்திருந்தால், எந்த ஆபரேட்டரும்:

  • நீக்கிய இன்வாய்ஸை மீட்டெடுத்து அது நீக்கப்பட்டதை மறைக்கலாம்
  • முழுத் தணிக்கைத் தடத்தையும் பார்த்து தாம் கண்காணிக்கப்படுவதை அறியலாம்
  • முறைகேட்டின் சான்றை அழிக்கப் பதிவுக் குறிப்புகளை நிரந்தரமாக நீக்கலாம்

வணிக உரிமையாளர் அல்லது நிர்வாகி மட்டுமே இந்த உணர்திறன் மிக்க பகுதியை அணுக முடியும் என்பதைப் பூட்டு உறுதி செய்கிறது. ஆபரேட்டர்களாக உள்நுழையும் ஊழியர்களுக்கு இந்த டேப் தெரியவே தெரியாது.

உங்கள் username ஐயும் முன்பு சேமித்த Recovery Key ஐயும் உள்ளிடுங்கள் (மேலே பார்க்கவும்).
3
ஒரு புதிய கடவுச்சொல்லை உள்ளிட்டு உறுதிப்படுத்துங்கள் (குறைந்தது 8 எழுத்துகள்).

அத்தியாயம் 17 — உங்கள் தரவு

17. உங்கள் தரவு — இருப்பிடம், பேக்கப் மற்றும் மீட்டமைப்பு

உங்கள் தரவு எங்கே உள்ளது?

உங்கள் எல்லாத் தரவும் உங்கள் Windows PC யில் ஒரே SQLite தரவுத்தளக் கோப்பில் சேமிக்கப்படுகிறது:

C:\Users\[YourWindowsName]\AppData\Roaming\BrandAccShay\inventory.db

ஒரு தானியங்கிப் பேக்கப் கோப்புறையும் உள்ளது:

C:\Users\[YourWindowsName]\AppData\Roaming\BrandAccShay\backups\

Accelent ஒவ்வொரு முறை தொடங்கும்போதும் தானாகப் பேக்கப் எடுக்கிறது. சமீபத்திய 10 பேக்கப்கள் வரை தானாக வைக்கப்படுகின்றன.

💡 AppData ஐ விரைவாகத் திறக்க Windows+R அழுத்தி, %APPDATA%\BrandAccShay தட்டச்சு செய்து Enter அழுத்துங்கள்.

கையால் பேக்கப் எடுத்தல்

1
Settings → ⚙️ App Settings → 💾 Backup Data க்குச் செல்லுங்கள்.
2
பேக்கப் கோப்பை எங்கே சேமிப்பது என்று தேர்ந்தெடுங்கள் (USB டிரைவ், Google Drive கோப்புறை, அல்லது வெளிப்புற ஹார்ட் டிஸ்க்).
3
Save கிளிக் செய்யுங்கள். பேக்கப் உங்கள் எல்லாத் தரவும் உள்ள ஒரே .db கோப்பு.
✅ பரிந்துரைக்கப்படும் பேக்கப் முறை:
• தினமும்: Accelent தானாகப் பேக்கப் எடுக்கட்டும் (தொடங்கும்போது தானாக நடக்கிறது)
• வாரந்தோறும்: USB டிரைவ் அல்லது Google Drive க்குக் கையால் பேக்கப்
• மாதந்தோறும்: முழு AppData\BrandAccShay கோப்புறையையும் வெளிப்புற ஹார்ட் டிஸ்க்கில் நகலெடுங்கள்

பேக்கப்பிலிருந்து மீட்டமைத்தல்

1
Settings → ⚙️ App Settings → 📂 Restore Data க்குச் செல்லுங்கள்.
2
உங்கள் பேக்கப் .db கோப்பைத் தேடிக் கண்டுபிடியுங்கள்.
3
Open கிளிக் செய்யுங்கள். Accelent தற்போதைய தரவுத்தளத்தைப் பேக்கப்பால் மாற்றும். செயலி தானாக மீண்டும் தொடங்கும்.
⚠ பேக்கப்பிலிருந்து மீட்டமைப்பது தற்போதைய எல்லாத் தரவையும் பேக்கப் தரவால் மாற்றுகிறது. பேக்கப் தேதிக்குப் பின் உள்ளிட்ட எல்லாப் பரிவர்த்தனைகளும் இழக்கப்படும். கடுமையான பிழையிலிருந்து மீள வேண்டியிருக்கும்போது மட்டுமே மீட்டமையுங்கள்.

☁️ Cloud Backup — தானியங்கி, மறைகுறியாக்கப்பட்ட, வேறிடப் பேக்கப்

மேலே உள்ள கைப் பேக்கப்கள் உள்ளூரில் சேமிக்கப்படுகின்றன — உங்கள் PC தொலைந்தால், திருடப்பட்டால் அல்லது சேதமடைந்தால், உள்ளூரில் மட்டும் உள்ள பேக்கப்பும் அதனுடன் போகலாம். Cloud Backup இதைத் தீர்க்கிறது: உங்கள் சொந்த PC யிலேயே தரவுத்தளத்தின் நகலை மறைகுறியாக்கி, உங்கள் சொந்த கிளவுட் சேமிப்புடன் (OneDrive, Google Drive, Dropbox போன்றவை) ஒத்திசைக்கும் கோப்புறையில் சேமிக்கிறது. உங்கள் மென்பொருள் வழங்குநர் உங்கள் தரவை ஒருபோதும் பார்ப்பதில்லை — கோப்பு உங்கள் கணினியை விட்டு வெளியேறும் முன்பே மறைகுறியாக்கப்படுகிறது.

Cloud Backup அமைத்தல்

1
Settings → ⚙️ App Settings → ☁️ Cloud Backup க்குச் சென்று Set Up Cloud Backup கிளிக் செய்யுங்கள்.
2
Browse... கிளிக் செய்து உங்கள் கிளவுட் சேமிப்புச் செயலி ஒத்திசைக்கும் கோப்புறையைத் தேர்ந்தெடுங்கள் (உதா. உங்கள் OneDrive அல்லது Google Drive கோப்புறை).
3
ஒரு Backup Password தேர்ந்தெடுத்து (குறைந்தது 8 எழுத்துகள்) உறுதிப்படுத்துங்கள். இந்தக் கடவுச்சொல் ஒவ்வொரு பேக்கப்பையும் மறைகுறியாக்குகிறது — அதை நினைவில் வையுங்கள், உங்கள் நிர்வாகி உள்நுழைவுக் கடவுச்சொல்லிலிருந்து தனியாக வையுங்கள்.
4
Continue கிளிக் செய்யுங்கள். Accelent முதல் பேக்கப்பை எடுத்து, பின்னர் மூடும் முன் சேமித்ததாக நீங்கள் உறுதிப்படுத்த வேண்டிய பெட்டியில் ஒரு முறைக்கான Recovery Code ஐக் காட்டும்.
⚠ Cloud Backup கடவுச்சொல்லும் Cloud Backup recovery code உம் உங்கள் உள்நுழைவு Recovery Key யிலிருந்து வேறானவை (அத்தியாயம் 16). குழம்பாமல் இருக்க அவற்றைத் தெளிவாகத் தனித்தனியாகக் குறியிட்டு வையுங்கள்:
  • Login Recovery Key — உள்நுழைவுத் திரையில் உங்கள் செயலிக் கடவுச்சொல்லை நீங்களே மீட்டமைக்கிறது, சப்போர்ட் தேவையில்லை.
  • Cloud Backup password — உங்கள் கிளவுட் பேக்கப் கோப்புகளைத் திறக்கிறது; ஒவ்வொரு மீட்டமைப்பிலும் தேவை.
  • Cloud Backup recovery code — Cloud Backup கடவுச்சொல்லை மறந்தால், சப்போர்ட்டின் release code உடன் சேர்ந்து மட்டுமே பயன்படும்.

பட்டியலிலிருந்து வேண்டிய பேக்கப்பைத் தேர்ந்தெடுத்து (சமீபத்தியது முதலில்) உங்கள் Backup Password ஐ உள்ளிடுங்கள்.

மீட்டமைப்பு எச்சரிக்கையை உறுதிப்படுத்துங்கள். தற்போதைய தரவு மாற்றப்படும் — பின்னர் செயலியை மீண்டும் தொடங்குங்கள்.
💡 Cloud Backup கடவுச்சொல்லை மறந்துவிட்டீர்களா? மீட்டமைப்புச் சாளரத்தில் "Forgot password? Use recovery code instead" கிளிக் செய்யுங்கள். இந்த வழிக்கு அமைக்கும்போது சேமித்த recovery code மற்றும் உங்கள் மென்பொருள் வழங்குநரின் சப்போர்ட்டிலிருந்து ஒரு release code இரண்டும் தேவை — எந்த ஒரு பகுதியாலும் தனியாக உங்கள் பேக்கப்பைத் திறக்க முடியாமல் இருக்கவே இது.
✅ Cloud Backup விருப்பத்திற்குரியது, Accelent ஒவ்வொரு தொடக்கத்திலும் ஏற்கனவே எடுக்கும் தானியங்கி உள்ளூர்ப் பேக்கப்களிலிருந்து வேறானது — வலுவான பாதுகாப்புக்கு இரண்டையும் பயன்படுத்துங்கள்: அதே PC யில் விரைவான மீட்புக்கு உள்ளூர்ப் பேக்கப்கள், PC யே தொலைந்தால் அல்லது சேதமடைந்தால் பாதுகாப்புக்கு Cloud Backup.

⚠ உங்கள் உரிமம் அது செயல்படுத்தப்பட்ட PC யுடன் பிணைக்கப்பட்டுள்ளது. மாற்றும் முன், உரிமத்தைப் புதிய PC க்கு மாற்ற சப்போர்ட்டைத் தொடர்பு கொள்ளுங்கள்; பின்னர் Settings → 🔑 License இலிருந்து செயல்படுத்துங்கள்.

18. புதிய பதிப்புக்கு மேம்படுத்துதல்

Accelent இன் புதிய பதிப்பு வெளியானதும், இந்தப் படிகளைப் பின்பற்றுங்கள். மேம்படுத்தும்போது உங்கள் தரவு எப்போதும் பாதுகாப்பாக இருக்கும், ஏனெனில் தரவுத்தளம் நிரல் கோப்புகளிலிருந்து தனியாக உள்ளது.
